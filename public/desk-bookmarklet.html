🔖 Install Bookmarklet — Deskripsi Skin

Sekali install, dipakai berulang tanpa DevTools lagi. Klik saat sudah di halaman hasil cek skin cekskin.com.

1

Tampilkan bookmarks bar

Chrome/Edge: tekan Ctrl+Shift+B (Windows) atau Cmd+Shift+B (Mac) kalau belum kelihatan.

2

Drag tombol ini ke bookmarks bar

Klik-tahan tombol kuning di bawah ini, lalu seret ke bar bookmark di atas browser.


📋 Deskripsi Skin
⚠️ Kalau di-klik biasa (bukan di-drag) di halaman ini, tidak akan berfungsi apa-apa — dia harus jadi bookmark dulu, baru dipakai di tab cekskin.com.
3

Pakai setiap kali cek skin

Penting: klik bookmark DULU sebelum cari ID, bukan sesudahnya — begini urutannya:

1. Buka cekskin.com, di halaman mana saja (boleh homepage)
2. Klik bookmark 📋 Deskripsi Skin di bookmarks bar → muncul alert "Siap!"
3. Masukkan Game ID & klik Cari Skin seperti biasa (pakai kredit kamu)
4. Begitu hasil skin tampil, modal deskripsi otomatis muncul → klik Copy Deskripsi

Bookmark cuma perlu diklik ulang kalau kamu reload/buka tab baru cekskin.com.

Bookmarklet ini cuma jalan di browser kamu sendiri, saat kamu klik manual, di tab yang lagi login cekskin.com. Tidak ada data yang dikirim ke server lain — semua proses (ambil data & format teks) terjadi lokal di browser.
