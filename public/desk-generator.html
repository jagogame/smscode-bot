📋 Deskripsi Skin Generator

Paste data skin (hasil cek dari cekskin.com) → auto-jadi format "Desk:" siap pakai buat listing jual akun.

1. Paste Data Skin

Buka DevTools (F12) → tab Network saat cek skin di cekskin.com → cari request GET /api/players/{id}/skins → klik kanan → Copy Response → paste di bawah ini. Tool ini terima format JSON {"skins":[...]} atau langsung array [...].
Urutan otomatis: Legend → Grand → Exquisite. Rarity lain (Deluxe/Exceptional/Common) disembunyikan.
